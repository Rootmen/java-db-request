Уровни логирования и их назначение
###### ERROR (Критические ошибки)
"Целевой запрос не найден" - указанный именованный запрос отсутствует
"Ошибка основного запроса" - сбой в запросе, который должен вернуть результат
"Ошибка транзакции" - проблемы при коммите/откате транзакции
"Ошибка операции" - общий сбой при выполнении

###### INFO (Информационные сообщения)
"Обработка результатов из" - начало обработки результатов основного запроса

###### DEBUG (Отладочная информация)
"Транзакция начата" - старт транзакции с указанием количества запросов
"Выполнение запроса" - выполнение каждого отдельного запроса
"Ошибка вспомогательного запроса" - сбой в неосновных запросах
"Транзакция завершена" - успешное завершение транзакции

###### TRACE (Детальная трассировка)
"Параметры запроса" - значения всех параметров SQL-запроса
"Элемент результата" - отдельные элементы результирующего набора

Формат сообщений
Все сообщения имеют единый формат:
[хранилище:запрос] текст сообщения
где:
хранилище - имя хранилища данных
запрос - имя выполняемого запроса
